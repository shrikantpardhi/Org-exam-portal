# Master PRD v1.0

## 04. User Personas

## 1. Super Administrator

Responsible for platform-wide administration, configuration, compliance, and high-level oversight.

### Needs
- Control organization settings
- Manage business rules
- View audit information
- Monitor platform health

## 2. Organization Administrator

Responsible for daily organization management and operational control.

### Needs
- Manage users and roles
- Manage academic masters
- Oversee commerce and collections
- Monitor operations and support workflows

## 3. Faculty / Content Author

Responsible for creating and maintaining questions, templates, and assessments.

### Needs
- Create and edit questions
- Build assessments
- Run validations
- Import and export content

## 4. Reviewer

Responsible for reviewing content and approving questions, blueprints, and assessments.

### Needs
- Review drafts
- Validate correctness
- Approve or reject submissions
- Track comments and history

## 5. Student

Consumes assessments and learning content.

### Needs
- Discover and purchase access
- Take assessments
- Review results
- Track progress and recommendations

## 6. Support Executive

Assists users and resolves issues quickly.

### Needs
- Search user history
- Inspect sessions and attempts
- Resolve access or result issues
- View audit trails

## Persona Principles

- One user may have multiple roles.
- Permissions are assigned through roles.
- Persona experience changes based on role access.

## Status

Frozen architecture baseline for Version 1.0.
