# Architecture Freeze v1.0

This document records the frozen product and engineering decisions for the Smart Competitive Examination Platform.

## Frozen Decisions
- Single organization deployment
- Modular monolith architecture
- Spring Boot 4 backend
- Next.js frontend
- PostgreSQL database
- Redis cache
- JWT authentication
- RBAC authorization
- Versioned blueprints, questions, assessments, answer keys, and results
- Snapshot-based assessment delivery
- Audit-first operations
- Markdown as the source of truth for documentation
