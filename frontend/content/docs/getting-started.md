# Getting started

An organization is brought on by a system administrator, who creates the organization and its first
organization admin. From there the organization admin owns the day-to-day setup.

## Sign in

There are three portals, one per audience. Each checks that the account matches its audience and
refuses accounts that belong elsewhere:

- /login/student — for students.
- /login/organization — for organization admins and staff.
- /login/admin — for system administrators.

Sign in with your email address and password. A newly provisioned account is asked to set a new
password on first sign-in.

## The first-run path

1. The system admin creates the organization and the first admin account.
2. The admin signs in at the organization portal and is asked to set a new password.
3. The admin adds staff, reviewers, and students, then configures the organization.
4. Authors write questions and blueprints; administrators schedule assessments.
5. Students sign in, take the timed attempt, and view published results.
