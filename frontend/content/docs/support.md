# Support

Support is provided by your organization's support team and the platform operator.

## Getting help

- If you are a student, contact your organization's support team for account and exam issues.
- If you are an administrator, contact the platform operator for provisioning and platform issues.
- For sales and trial enquiries, use the contact form on the landing page.

Include the page and, where available, the request identifier shown with an error, so the issue can
be traced.
